# meta-ai-hackathon

Two independent projects. Each has its own `package.json` and lockfile; run
commands from inside the project directory.

- **`web-app/`** — Saltbreak Surf Co. + Workflow Atlas (Next.js apps, worker,
  packages). See [`web-app/README.md`](web-app/README.md).
- **`desktop-app/`** — Ghost Operator (Electron app: Saltbreak target window,
  recording toolbar, sidecar, studio). See
  [`desktop-app/README.md`](desktop-app/README.md).
